# SCREEN 5 terrain tiles

Generated by `python tools/convert_terrain.py` from nine original world shapes
placed into an authored 4096×212 scene. This does not decode original maps.

- `tiles.sc5`: 44 unique 16×16 tiles, tile-major, two 4-bit pixels per byte;
  5,632 bytes total, with no BSAVE header.
- `map.bin`: 256 columns × 6 rows of byte tile IDs, **column-major**. Tile rows
  begin at screen y=128; the last tile's visible portion ends at y=211.
- `bank_4.bin`: tiles followed by map, 7,168 bytes; ROM offset 32,768 in the
  64 KiB ASCII8 prototype. It loads through CPU bank 1 at startup.
- `palette.bin`: 32 V9958 register bytes. Aircraft palette slots 0–11 remain
  unchanged; four extra colors serve foliage and soil.
- `scene.indices`: complete 4096×212 converted pixel reference, one byte/pixel;
  used by host/emulator verification, **not included in the ROM**.
- `source-scene.png` / `msx-scene.png`: original-palette and reduced-palette
  previews of the authored scene. The MSX preview uses linear RGB3 expansion.
- `manifest.json`: provenance, placement, palette mapping, tile-size comparison,
  VRAM contract, bundle digest and storage counts.

The renderer requires rows 128–143 to be sky index 0 and rows 208–211 to be
ocean index 1; conversion and tests enforce both. Only four 16-pixel tile rows
vary during streaming. Tiles cache below the aircraft atlas, starting at page
2 row 180, and do not overlap display-page footprint backups.
