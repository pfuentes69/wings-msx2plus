# Compiled close and distant a.map scenery

Generated by `python tools/convert_mission.py`; `--check` checks every output.

- `tiles.sc5`: 490 shared 8×8 SCREEN 5 tiles, 15,680 bytes.
- `map.bin`: 1,072 u16le offsets and deduplicated count:u8/tile:u16le runs,
  totaling 6,356 bytes. Each column expands to nineteen tiles.
- The first 952 columns describe close scenery; the last 120 describe distant
  scenery from `8thscale.shp`. World navigation is 7,608 pixels; its far projection
  is 951 pixels. The padded references are 7,616 and 960 pixels wide.
- `scene.indices`/`scene.png` and `far.indices` are renderer references, not
  complete bitmaps embedded in the ROM.
- `bank_4.bin` through `bank_6.bin` contain the 22,036-byte tile/map bundle.
- `palette.bin` adapts the shared aircraft/terrain palette with two blue tones
  from the original `ocean.palette`. Waves use its CMAP fitted to five blue slots.
- `manifest.json` retains source hashes, layout, tile comparisons and memory use.

Tiles are stacked in vertical groups of nine on pages 2/3, rows 180–251.
Source-canvas rows 64–211 map to display rows 24–171. Source baseline 201 thus
appears at 161, preserving eleven water/ground lines above the fixed dashboard.
Static map/cache RAM is 8,954 bytes, excluding other program state and stack.

See `docs/scenery-fidelity.md` for the source-backed rules and explicit remaining
adaptations. Original source files remain unchanged.

The current mission decoder applies verified source clear/set-plane constants
and raw-plane transparency rather than the earlier base-colour OR hypothesis.
