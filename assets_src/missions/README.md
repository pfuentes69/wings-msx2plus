# Original mission-strip reconstruction

Generated by `python tools/decode_mission.py`; `--check` verifies the outputs.

- `inventory.json`: bounded structural decode of all 15 supplied map files.
- `evidence.json`: original executable digest, checked instruction bytes and the
  recovered 184-entry world-shape name table.
- `a-map.json`: every original word, its offset, decoded fields and surface runs.
- `a-scene.json`: 75 drawn normal-scale shapes, source record hashes/origins and
  14 explicitly skipped entries (13 absent normal-scale `bumb` shapes and one
  special marker ID 275).
- `a-source.png` / `a.indices`: static original-palette side-view adaptation of
  the strip, with source-backed X/depth/shape selection and authored ground fill
  and baseline translation. This is not a capture from the original game.

Original maps, shapes and executable remain unchanged. Copyrights remain with
their respective owners. See `docs/mission-map.md` for established fields,
uncertainties, source evidence, timing and prototype limitations.
