# Recovered source artwork

`hellcat/` contains 52 indexed PNG aircraft frames decoded from the supplied
original Hellcat archive, plus a contact sheet and provenance manifest.
See `docs/format-shp.md` for evidence, assumptions and reproduction commands.

Original game artwork remains copyrighted by its respective owners.
These decoded files are source-derived research materials; decoding does not
grant redistribution rights. Preserve the manifest alongside these images.
